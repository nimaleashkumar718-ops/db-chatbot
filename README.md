# DB Chatbot

A chatbot that answers questions about a SQLite database using the Gemini API.

## How to run
1. Install Python, then run: pip install google-genai
2. Get a free API key from aistudio.google.com
3. Set your key in the terminal (PowerShell): $env:GEMINI_API_KEY="your-key"
4. Run: python setup_db.py
5. Run: python bot.py

Never put your API key inside the code files.

Built while learning how AI tools and databases work.
